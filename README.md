# Gallery4ComfyUI

**双来源 AI 绘图作品管理工具** —— 把 ComfyUI / Stable Diffusion WebUI 的输出图片
集中起来浏览、搜索、筛选、收藏，并且能**跟着音乐播放**。

支持两种用法：

| 用法 | 适合 | 启动方式 |
|---|---|---|
| **独立桌面版** | 只想看图，不想开 ComfyUI | 双击 `Gallery4ComfyUI.exe` |
| **ComfyUI 插件** | 画完就想看图 | 节点里点「打开图库」 |

---

## 功能

### 图库

- **双数据源**：ComfyUI `output/` 与 SD WebUI `outputs/`，外加视频与收藏页
- **搜索**：文件名 / 正向提示词 / 负向提示词，毫秒级内存过滤
- **高级搜索**：tag 统计补全（按使用次数排序）、多 tag 组合（AND）、tag 屏蔽（黑名单）
- **筛选**：模型 / 采样器 / 步数 / CFG / 尺寸 / 仅收藏
- **排序**：最新 / 最旧 / 随机 / 文件名
- **收藏夹**：多夹管理、拖拽归档、拉框多选批量操作
- **画师库**：48,000+ 画师数据，按原型 / 出身 / 主题 / 构图 / 尺度筛选
- **灯箱**：键盘导航、PNG 元数据、复制、下载、定位文件
- **打包**：按 LoRA 或大模型分组导出 zip
- 浅色 / 深色主题、网格密度调节、中英双语

### 幻灯片播放

独立窗口，**四种播放模式**：

| 模式 | 说明 |
|---|---|
| 每秒 N 张 | 固定张数（最高 60/秒） |
| 每张 N 秒 | 固定停留时长 |
| 自适应 | 按方向键打节奏，之后照你的节奏自动播 |
| 🎵 **跟音乐** | **跟着电脑正在播放的音频切图** |

**11 种转场**：瞬切 / 淡入淡出 / 左右滑 / 上下滑 / 缩放推拉 / 翻卡 3D /
时钟擦除 / 百叶窗 / 像素化 / 节奏型 / 随机

**跟音乐模式**的特别之处：

- 抓的是**系统音频输出**（耳机/扬声器里真正在放的声音），不是麦克风
- **不需要任何权限弹窗**，采集在后台完成
- 阈值支持两种判定：
  - **动态**：阈值跟着音乐自身的响度起伏走。实测**音量差 100 倍，触发结果完全一致**
  - **固定**：绝对 dB 门槛，适合想卡一个明确标准的场景
- 灵敏度 1–50 可调，实时显示识别到的 BPM
- 自动跳过前奏（无鼓点时不切图）

## 快速开始

### 独立桌面版

1. 解压到任意目录（**不要放 C 盘根目录**，避免权限问题）
2. 双击 `Gallery4ComfyUI.exe`
3. 首次运行会引导你选 ComfyUI 输出目录（不确定就点「浏览」）
4. 开始看图

> 免安装、免 Python 环境。首次打开会建索引，之后秒开。

### ComfyUI 插件

1. 把 `Gallery4ComfyUI` 文件夹放进 `ComfyUI/custom_nodes/`
2. 在画布中添加节点「**Gallery4ComfyUI**」（分类 Anima）
3. 点击节点上的「**打开图库**」按钮

> 插件版是**懒启动**的：ComfyUI 启动时零开销，点开图库才建索引。

## 常见问题

**Q：图库打开了但没有图片？**
检查设置里的「ComfyUI 输出目录」是否指向正确的 `output` 文件夹。

**Q：跟音乐模式没反应？**
确认电脑正在播放声音（耳机或扬声器），然后点「开始听」。
没有权限弹窗是正常的 —— 采集在后台完成。

**Q：跟音乐切得太快/太慢？**
调「灵敏度」。往右更灵敏。也可以切换「固定」模式手动卡门槛。

**Q：图片加载慢？**
首次打开要建索引。索引建好后会缓存，之后秒开。

**Q：改了图片目录，怎么重新扫描？**
顶栏的「🔄 ComfyUI」/「🔄 WebUI」按钮可以重建索引。
